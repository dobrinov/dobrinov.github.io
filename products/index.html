Rust · WebAssembly · Open source

Small tools.
That are also libraries.

Each one does one job, runs in your terminal and your browser from the same engine, keeps its data as text in your repository, and works with your AI agent. Install any of them with Homebrew, or grab a binary for macOS, Linux or Windows.

Boards · Planning · AI

shape

From a messy idea to a plan everyone gets. One board for the whole project: mindmaps, kanban, timelines, wireframes and flows, decision records and charts, with perspectives for each audience and slides in one click. The AI you already pay for (Claude, ChatGPT or Gemini) sorts what you throw at it, and a whole board copies as a prompt to build from. It is plain text in your repository.

brew install dobrinov/tap/shape

Databases · Git · Review

schema

Interactive ER diagrams and visual git diffs for Postgres structure.sql, MySQL dumps, SQLite schemas and Rails schema.rb files. Focus on the tables that matter and review every migration as a picture.

brew install dobrinov/tap/schema

Browser · Chromium · AI agents

circle

The calm, sidebar-first browser in the spirit of Arc. Spaces with their own colours, Spotlight (⌘K), split view, docked DevTools, screen recording to video or GIF, and a private fap mode. Built in Rust on Chromium, with an MCP server so your AI agent can drive it. Signed, notarized and self-updating.
